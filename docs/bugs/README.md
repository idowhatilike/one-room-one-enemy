# Bugs

Mỗi hồ sơ dùng `NNN-slug.md`: trạng thái OPEN/FIXED, triệu chứng, môi trường,
bước tái hiện, expected/actual, test FAIL, nguyên nhân/giả thuyết, fix plan,
AC/Verify, số lần vá và kết quả. Giữ bằng chứng hai lần vá thất bại nếu phải dừng.
Chỉ FIXED khi reproduction và regression cần thiết PASS. Không ghi bug chưa được
quan sát như sự thật; không tự chuyển hồ sơ cũ vào archive.
