# Plans

Mỗi plan dùng `NNN-slug.md`, có Status DRAFT/APPROVED/DONE, mục tiêu, phạm vi,
bằng chứng code, phương án, file ảnh hưởng, rủi ro, task với AC và Verify, Change log.
Chỉ APPROVED khi có phê duyệt thực tế; chỉ DONE khi mọi task đã verify PASS.
Plan có mở rộng scope phải được duyệt phần thay đổi. Khi kết thúc, cập nhật STATE;
chuyển vào archive chỉ sau khi người dùng cho phép.
