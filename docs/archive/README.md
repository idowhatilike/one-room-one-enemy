# Archive

Nơi giữ plan/bug đã kết thúc khi việc chuyển file được người dùng cho phép.
Giữ loại hồ sơ và mã gốc, ví dụ `plan-001-slug.md`, `bug-001-slug.md`; cập nhật
link tham chiếu khi chuyển. STATE chỉ giữ kết quả hiện tại và bước tiếp theo,
không sao chép toàn bộ lịch sử. Hiện chưa có hồ sơ được archive.
